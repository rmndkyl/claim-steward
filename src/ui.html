An airdrop claim desk
that can be checked.

Airdrop distributions ask people to trust a spreadsheet. This agent replaces the trust with three things anyone can verify: an ed25519 signature on every decision, a Merkle path into a commitment published before the first claim, and a hash-chained ledger so decisions cannot be rewritten after the fact.
